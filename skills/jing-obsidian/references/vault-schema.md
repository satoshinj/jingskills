# 本地知识库结构（PARA）

## 设计目标

这套结构服务于两个循环：资料逐步变成可复用知识；知识与真实材料被装配成内容并在发布后回流。它不是百科全书，也不要求一次整理完历史笔记。

布局采用 **PARA**，标识 `para-v1`。内容生产不引入自己的第二套目录体系——**一篇内容就是一个项目**，它的全部工作产物（成稿包、调研、草稿、封面、正文配图）留在同一个项目目录里。

## 目录职责

| 目录 | 职责 |
|---|---|
| `Clippings/` | Web Clipper 捕获落点。**只读**：原件不得改写、移动或删除 |
| `00-Inbox（灵感库）/` | 新资料、临时想法、待评估选题与剪藏审核卡；整理后应清空 |
| `01-Projects（项目）/<项目名>/` | 正在推进的内容项目：成稿包、调研、草稿、封面、配图与产出 |
| `02-Areas（资产）/<主题>/概览.md` | 经判断、可长期复用的结论 |
| `03-Resources（资源）/<主题>/` | 外部原文、网页、X、视频、文档与附件 |
| `04-Archive（归档）/<主题>/` | 已发布、已结束或按日期保留的正式归档 |
| `05-Skills（技能）/<技能名>/` | 已跑通、可重复调用的方法与流程 |
| `indexes/` | 全库导航、来源规则、运营台账与维护记录 |

六大分类下**优先只保留「主题」一层**。附件、月份等确有必要时才用第二层。内容项目目录内部可以按需要放子目录（如 `封面/`、`配图/`），因为那是项目产出而非分类层。

## 项目目录内部约定

`01-Projects（项目）/<YYYY-MM-DD-主题>/`：

| 文件/目录 | 内容 |
|---|---|
| `成稿包.md` | 问题、判断、事实边界、个人材料、情绪曲线 |
| `调研.md` | 事实清单、来源索引、数据快照 |
| `<标题>.md` | 当前有效的完整草稿（一个主题只留一份） |
| `封面/` | 封面任务包、无字底图、各平台成品 |
| `配图/` | 正文配图，按正文顺序编号 |

外部原文不放项目目录，进 `03-Resources（资源）/<主题>/` 并从项目里链接过去——同一份资料可能被多个项目引用，不留第二份副本。

## 知识分类

长期知识使用 frontmatter 的 `kind` 作为分类真源：

- `concept`：概念
- `entity`：人物或组织
- `question`：值得持续回答的问题
- `viewpoint`：可辩论的判断
- `case`：案例
- `playbook`：方法与操作方案
- `map`：主题地图
- `guide`：导航与系统说明

`02-Areas（资产）/` 下不按 `kind` 建子目录，分类靠 frontmatter。不要因为移动文件而批量改写知识类型。

`概览.md` 必须包含：结论、适用范围、风险或不采用项、来源链接或路径。

## 最小内容流

1. Web Clipper 采集停在 `Clippings/`。**逐项明确处理后**才移动或复制到 `00-Inbox（灵感库）/`，保留来源 URL、日期与原文。
2. 分类时原文进 `03-Resources（资源）/<主题>/`；值得长期复用的判断写进 `02-Areas（资产）/<主题>/概览.md`，优先更新既有页而不是一事一页。
3. 决定写成内容时建 `01-Projects（项目）/<YYYY-MM-DD-主题>/`，先确认问题、判断、事实边界、个人材料与情绪曲线。
4. 调研与完整正文都留在项目目录内。
5. 用户确认发布后，发布版本归档到 `04-Archive（归档）/<主题>/`。
6. 发布形成的新观点、案例和方法回流为 `02-Areas（资产）/` 的独立判断，**不把整篇文章复制进资产层**。
7. 跑通的流程沉淀到 `05-Skills（技能）/<技能名>/`。

## 命名与版本

- 项目目录：`YYYY-MM-DD-主题/`
- 草稿：`<标题>.md`（项目目录内已有日期，文件名不重复日期）
- 配图：`<两位序号>-<短标识>.png`，序号按正文出现顺序
- 文件名使用有意义的人类语言，不用随机编号代替主题。内部新建目录优先中文。
- 同一主题只保留一份当前草稿；历史版本交给 Git、同步服务或 `04-Archive（归档）/` 处理。

## 边界

- 不写入密码、token、私钥、认证文件、个人隐私，或可直接操作生产与家庭设备的细节。
- 外部作者的价格、效果、权限、兼容性和案例都是**来源主张**，未经独立核验不得写成事实。
- 不覆盖、移动或删除用户已有笔记。`00-Inbox（灵感库）/` 不是归档区。
- 发现重复、失效、冲突或孤页时，修复索引或标记「待核验」，不要静默抹平。
